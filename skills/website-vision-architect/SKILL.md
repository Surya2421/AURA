# Website Vision Architect Skill (`website-vision-architect`)

The `website-vision-architect` is responsible for establishing the artistic and architectural thesis of the website *before* any frontend code or styling is written. It prevents the primary failure mode of AI web design: defaulting to generic, indistinguishable SaaS templates.

---

## 1. Core Responsibilities

1. **Brand Essence & Metaphor Formulation**: Uncover the unique narrative hook, emotional resonance, and domain reality of the project.
2. **Archetype Selection**: Select or synthesize a deliberate spatial layout archetype (e.g., Asymmetric Editorial, Command & Control Precision Deck, Kinetic Gallery, Split Bento).
3. **Anti-Cliché Divergence Check**: Actively audit the proposed concept against banned AI clichés (purple glow on black, 3-card grids, generic marketing buzzwords).
4. **Narrative Information Architecture (IA)**: Map the user's journey as an authentic progression of ideas, proof points, and interactive experiences, strictly barring fabricated testimonials or fake metrics.
5. **Handoff Blueprint Generation**: Produce a structured Vision Concept Document for the `signature-art-direction` and `frontend-experience-engineer` skills.

---

## 2. Layout Archetype Catalog

The architect must choose or combine layout archetypes based on domain intent:

### Archetype A: The Asymmetric Editorial Spread
- **Character**: Literary, prestigious, cinematic, deliberate.
- **Visual Mechanics**: High-contrast serifs, deliberate off-axis alignment, multi-column editorial rhythm, ample negative space, curated pull quotes, full-bleed imagery with tactile borders.
- **Best Suited For**: Architecture studios, luxury brands, creative agencies, long-form journalism, research institutions, personal portfolios.

### Archetype B: The Command & Control Precision Deck
- **Character**: Technical, authoritative, high-density, analytical.
- **Visual Mechanics**: Geometric grotesques, tabular monospace metadata, modular inspector rails, live telemetry status pills, embedded syntax-highlighted execution blocks, high-contrast dark surfaces.
- **Best Suited For**: Developer tooling, cloud infrastructure, cryptography, trading platforms, AI laboratories.

### Archetype C: The Kinetic Showcase Gallery
- **Character**: Experiential, sensory, tactile, fluid.
- **Visual Mechanics**: Horizontal exploration rails, sticky vertical viewport anchors, transformational media pinned during scroll, micro-animations that respond directly to cursor/touch vectors.
- **Best Suited For**: Hardware products, visual artists, consumer electronics, design systems, fashion houses.

### Archetype D: The Split Hero & Evolutionary Bento
- **Character**: Pragmatic, direct, engaging, modern.
- **Visual Mechanics**: High-impact 50/50 split hero (textual thesis on left, interactive interactive preview/sandbox on right), transitioning into an asymmetric bento grid where each cell has a completely unique UI structure.
- **Best Suited For**: Modern software platforms, collaborative productivity tools, API-first utilities.

---

## 3. Anti-Cliché Verification Protocol

Before finalizing any concept, the architect MUST evaluate the proposed plan against the **Anti-Cliché Checklist**:

- [ ] **No Generic Hero Copy**: Does the headline say "Empower your workflow", "Supercharge your productivity", or "The all-in-one AI platform"? If yes, REJECT and replace with an authentic, domain-specific value statement.
- [ ] **No 3-Card Symmetric Feature Matrix**: Are three identical cards placed in a row with icons at the top, a 2-line title, and a 3-line paragraph? If yes, REJECT and redesign with asymmetric weights (e.g., 60/40 split, list with active preview, or interactive tabs).
- [ ] **No Faux Social Proof**: Are there fake reviews from fictional founders, or a row of blurred tech logos? If yes, REJECT immediately in accordance with Core Principle 3. Replace with verified engineering capabilities, open-source milestones, or clean asset-pending placeholders.
- [ ] **No Purposeless Radial Purple Orbs**: Is there a blurred purple/blue gradient circle centered behind a card? If yes, REJECT and replace with crisp border luminescence, chromatic shadows, or authentic ambient lighting.

---

## 4. Deliverable Format: The Vision Concept Document

The architect outputs a markdown artifact adhering to this structure:

```markdown
# Website Vision Concept: [Project Name]

## 1. Narrative Hook & Artistic Thesis
- **Core Narrative**: [What story does this website tell?]
- **Emotional Tone**: [e.g., "Austere yet warm; authoritative like a Swiss research monograph."]
- **Visual Metaphor**: [e.g., "A physical precision drafting table with brass accents and crisp ink lines."]

## 2. Selected Layout Archetype
- **Archetype**: [e.g., Asymmetric Editorial Spread]
- **Spatial Mechanics**: [How does content flow on desktop vs mobile?]
- **Whitespace Strategy**: [Aggressive luxury breathing room: 120px desktop section gaps, 48px mobile.]

## 3. Sectional Information Architecture (The User Journey)
1. **Masthead & Navigation**: [Brand identity, core section links, persistent status / CTA.]
2. **Hero Stage**: [Thesis statement, secondary context, primary engagement vector.]
3. **Core Narrative Section**: [The key differentiator, structured with non-generic visual balance.]
4. **Deep Dive / Capabilities**: [Asymmetric breakdown of features or work samples.]
5. **Authentic Proof / Case Studies**: [Real verified demonstrations or structured placeholders.]
6. **Closing Invitation / Footer**: [Clear conversion endpoint, copyright, semantic sitemap.]

## 4. Anti-Cliché Audit Summary
- Cliché risks identified and avoided: [Explicit notes on what tropes were deliberately rejected].

## 5. Decisions for Logging
- Log proposed archetype as `[PROPOSAL]` or `[INFERENCE]` in `references/DESIGN-DECISION-LOG.md`.
```
